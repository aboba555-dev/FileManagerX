## Полное описание
File Manager X — современный файловый менеджер для Android без рекламы и лишних разрешений.

Возможности:
• Обзор внутренней памяти и SD-карты, быстрый доступ к загрузкам, фото, музыке, видео и документам.
• Копирование, перемещение, переименование (в том числе пакетное), удаление и отправка файлов.
• Корзина: удалённые файлы можно восстановить.
• Архивы: просмотр и распаковка ZIP, 7z, RAR, TAR и других форматов, создание архивов, поддержка паролей.
• Анализ диска: список самых «тяжёлых» папок и файлов с размерами и долями.
• Поиск дубликатов файлов.
• Встроенный текстовый редактор.
• Миниатюры изображений и видео.
• Закладки и недавние папки.
• Режим root для доступа к системным разделам (по желанию).
• Светлая, тёмная и AMOLED-темы, динамические цвета Material You.
• Русский и английский языки.

Приложение не содержит рекламы и не отправляет ваши файлы никуда: все операции выполняются на устройстве.

## Зачем нужен доступ ко всем файлам (MANAGE_EXTERNAL_STORAGE)
File Manager X — файловый менеджер: его основная функция — просмотр и управление файлами во всей общей памяти устройства (копирование, перемещение, удаление, архивация). Без доступа ко всем файлам эти функции невозможны. Данные не передаются третьим лицам.
