# Политика конфиденциальности File Manager X

File Manager X не собирает, не хранит на серверах и не передаёт третьим лицам никаких персональных данных.

- Приложение работает полностью на устройстве. Файлы, имена файлов и содержимое памяти никуда не отправляются.
- Приложение не содержит рекламы, аналитики и сторонних трекеров.
- Доступ ко всем файлам (MANAGE_EXTERNAL_STORAGE) используется только для функций файлового менеджера: просмотр, копирование, перемещение, удаление, архивация и поиск дубликатов по запросу пользователя.
- Разрешение на уведомления используется только для показа прогресса файловых операций.
- Режим root включается пользователем вручную и используется только для доступа к системным разделам.
- Настройки (закладки, недавние папки, тема) хранятся локально на устройстве.
