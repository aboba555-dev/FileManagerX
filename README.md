# File Manager X

Проводник для Android 17 (API 37, minSdk 30): Jetpack Compose, Material You, иконки Font Awesome, поддержка root и встроенный архиватор. Без рекламы и без премиума.

## Что умеет

- **Файлы**: список и сетка, выбор, копирование, перемещение, удаление, переименование, поиск, свойства (размер, владелец, SELinux, контрольные суммы), текстовый редактор.
- **Вся файловая система**: `/`, `/system`, `/data` и т. д. Без root это чтение того, что разрешает система; с root — чтение и запись.
- **Root**: включается переключателем на главном экране. Все операции идут через root-процесс (libsu `RootService` + `FileSystemManager`), включая копирование потоками, `chmod`, перемонтирование разделов в rw/ro.
- **Корзина**: удалённое на общем хранилище уходит в `.FileManagerXTrash` на том же томе (без копирования между разделами), хранится 30 дней, восстанавливается на прежнее место. Системные пути (`/system`, `/data`) удаляются сразу. Отключается в настройках.
- **Миниатюры** изображений и видео (читаются через тот же root-канал, кэш 24 МБ).
- **Анализ диска**: карта-треемап и список по размеру, переход вглубь папок, размеры считаются параллельно и растут на глазах.
- **Дубликаты**: размер → первые 64 КБ → SHA-256; «оставить по одному», удаление через корзину.
- **Пакетное переименование**: шаблон (`{name}_{n}`, `{date}`, `{ext}`) или поиск/замена с regex, предпросмотр, конфликты блокируют применение.
- **Закладки и недавние папки** на главном экране.
- **Root «запись на 10 минут»**: раздел перемонтируется в rw, возврат в ro запускается отдельным root-процессом и сработает, даже если приложение убьют.
- **Foreground-сервис**: пока идёт копирование, архивация или распаковка, процесс держится уведомлением с прогрессом и кнопкой «Отмена».
- **Архиватор**

| Формат | Открыть / распаковать | Создать | Пароль |
|---|---|---|---|
| ZIP (и jar, apk, docx, …) | да | да | чтение и запись, AES-256 / ZipCrypto |
| 7z | да | да | чтение (в т. ч. зашифрованные заголовки) |
| RAR 1.5–4.x | да | нет | чтение |
| TAR, TAR.GZ, TAR.BZ2, TAR.XZ | да | да | — |
| GZ, BZ2, XZ, CPIO, AR/DEB, ARJ | да | нет | — |

  Есть проверка целостности, выборочная распаковка, удаление записей из ZIP, кодировка имён для старых ZIP (CP866, CP1251), защита от zip-slip.

## Сборка

Нужны JDK 17 и Android SDK 37. Android Studio (свежая) откроет проект как есть.

```bash
./gradlew :app:testDebugUnitTest      # тесты логики
./gradlew :app:assembleDebug          # app/build/outputs/apk/debug/
./gradlew :app:assembleRelease        # подписанный релиз (см. ниже)
```

Без Android Studio: запушьте проект на GitHub, workflow `.github/workflows/build.yml` соберёт APK и приложит его артефактом.

> Зависимость libsu берётся с JitPack, остальное — Google Maven и Maven Central.

## Публикация в RuStore

1. Скопируйте `keystore.properties.example` в `keystore.properties`, создайте ключ (команда в файле) и заполните поля.
2. Смените `applicationId` в `app/build.gradle.kts` на свой.
3. Впишите адрес страницы пожертвований в `DONATE_URL` там же.
4. `./gradlew :app:bundleRelease` или `assembleRelease`, загрузите артефакт.
5. В описании укажите, зачем нужен `MANAGE_EXTERNAL_STORAGE`: это файловый менеджер, другого способа нет.

## Устройство кода

```
app/src/main/java/app/filemanagerx/
├─ di/           ручной DI (AppContainer)
├─ core/         UiText — локализуемые строки из любого слоя
├─ domain/       чистая логика без Android: пути, сортировка, типы файлов
├─ service/      TaskService: foreground-уведомление для долгих операций
├─ data/
│  ├─ fs/        FileOperations, RootManager, FsIo, FileOpener, тома
│  ├─ archive/   ArchiveManager + читатели/писатели по форматам
│  ├─ trash/     TrashManager
│  ├─ settings/  DataStore
│  └─ tasks/     TaskCenter: долгие операции живут вне экранов
└─ ui/           Compose: home, browser, archive, editor, trash, analyzer, duplicates, settings, theme
```

`python3 tools/gen_strings.py` пересобирает `strings.xml` (EN и RU) и проверяет, что каждая `R.string.*` определена.

## Ограничения версии 1.0

- RAR5 не открывается (чисто JVM-декодера нет), создание RAR невозможно.
- 7z создаётся без шифрования.
- Не сделано: вкладки и двухпанельный режим, FTP/SFTP/SMB/WebDAV, RAR5, шифрование 7z, многотомные архивы, просмотр файла внутри архива без распаковки, лендинг для пожертвований.
- Проект ни разу не собирался: в среде разработки не было Android SDK. Первая сборка (`gradlew assembleDebug` или workflow в `.github/workflows`) может выдать ошибки компиляции, их придётся поправить.
